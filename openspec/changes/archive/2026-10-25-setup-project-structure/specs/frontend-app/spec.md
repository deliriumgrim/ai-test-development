# Spec Delta: frontend-app

## Purpose

Минимальное независимо запускаемое клиентское приложение в `frontend/` на TypeScript и React: стартовая страница, собираемая и запускаемая стандартными командами npm-проекта.

## ADDED Requirements

### Requirement: Клиентский код на TypeScript с UI на React

Клиентская часть SHALL быть реализована на TypeScript с использованием React и оформлена как самостоятельный npm-проект внутри `frontend/` с манифестом `package.json`.

#### Scenario: Проверка стека frontend

- **WHEN** разработчик открывает `frontend/`
- **THEN** он видит npm-проект, исходный код которого написан на TypeScript, а UI построен на React

### Requirement: Стартовая страница приложения

Приложение SHALL отображать стартовую страницу, подтверждающую работоспособность клиентской части, при открытии в браузере через dev-сервер.

#### Scenario: Открытие приложения в браузере

- **WHEN** dev-сервер запущен и разработчик открывает адрес приложения в браузере
- **THEN** отображается стартовая страница приложения без ошибок в консоли браузера

### Requirement: Независимая сборка frontend

Проект в `frontend/` SHALL собираться командой `npm run build` в производственную сборку без ошибок при наличии Node.js и содержимого каталога `frontend/` (после установки зависимостей).

#### Scenario: Производственная сборка

- **WHEN** разработчик устанавливает зависимости и выполняет `npm run build` внутри `frontend/`
- **THEN** сборка завершается успешно и создаёт артефакты производственной сборки

### Requirement: Независимый запуск frontend

Приложение SHALL запускаться командой `npm run dev` из каталога `frontend/`, поднимающей dev-сервер со стартовой страницей.

#### Scenario: Локальный запуск dev-сервера

- **WHEN** разработчик устанавливает зависимости и выполняет `npm run dev` в `frontend/`
- **THEN** dev-сервер запускается и приложение доступно по выведенному адресу
